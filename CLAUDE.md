# Notes for Claude

## Merging pull requests

The owner has given standing permission: Claude may merge its own pull
requests without asking first, once the change builds (`npx next build`)
and has been checked (run the affected flow, e.g. in a headless browser).
Always share the PR link and a short summary of what went live.

Still ask before anything that spends money, changes ad accounts, emails
customers, or deletes data — those aren't covered by this permission.
